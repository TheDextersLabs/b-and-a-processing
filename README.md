# B & A Processing

Official website and digital payment portal for **B & A Processing**, located in Aragon, Georgia.

## Overview

The primary objective of this repository and website is to serve as a fast, reliable mobile payment portal for customers settling processing fees, alongside providing core contact and service information for local hunters and livestock owners.

## Core Services

*   **Wild Game & Deer Processing:** Professional skinning, quartering, and custom cuts.
*   **Livestock Processing:** Dependable handling for local farm livestock.
*   **Specialty Products:** Custom grinds, breakfast sausage, and specialty blends.

Primarily serving Polk County, Bartow County, Floyd County, Paulding County, and Haralson County around Aragon, GA—with all hunters and farmers welcome.
